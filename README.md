# check-network-speed

Консольный скрипт на Python для замера скорости скачивания. Делает 10 запросов подряд к указанному адресу,
каждый раз дожидаясь полного ответа, и печатает среднее время запроса, общий объём и скорость.

## Требования

Python 3.8 или новее. Проверить версию:

- Windows: `python --version`
- macOS и Linux: `python3 --version`

## Запуск

Вместо адреса из примера можно подставить любой адрес файла.

### Windows (PowerShell)

```powershell
git clone https://github.com/nikito4kv/check-network-speed.git
cd check-network-speed
python speed_test.py https://proof.ovh.net/files/10Mb.dat
```

### macOS и Linux

```bash
git clone https://github.com/nikito4kv/check-network-speed.git
cd check-network-speed
python3 speed_test.py https://proof.ovh.net/files/10Mb.dat
```

## Единицы измерения

| Величина | Единица |
|---|---|
| Время | секунды (с) |
| Объём | мегабайты (МБ), 1 МБ = 1 000 000 байт |
| Скорость | мегабиты в секунду (Мбит/с), 1 Мбит = 1 000 000 бит |

## Что считается

Время запроса — от отправки запроса до последнего байта ответа. Оно складывается из двух частей:

- **ожидание ответа** — подключение к серверу и ожидание, пока он начнёт отдавать данные;
- **скачивание** — получение самого файла.

В итогах:

- **Скачано всего** — сумма байт всех 10 ответов.
- **Среднее время запроса** и **медиана времени запроса** — по полному времени 10 запросов.
- **Среднее ожидание ответа** — по 10 запросам.
- **Скорость скачивания** = общий объём × 8 / общее время скачивания. Ожидание ответа в скорость не входит.

## Ошибки

Если адрес неверный, сайт недоступен, сервер вернул ошибку (например, 404) или не ответил за 30 секунд,
скрипт печатает причину одной строкой и завершается с кодом 1.
